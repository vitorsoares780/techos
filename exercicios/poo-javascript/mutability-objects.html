8.4 — Mutabilidade de Objetos

Abra o console do navegador (F12) para ver os resultados.

Conceitos abordados

  • const vs. mutabilidade (o mito)
  • Object.freeze() — apenas leitura

  • Object.preventExtensions() — sem novas propriedades
